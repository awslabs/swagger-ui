# Repository Archived

## Background

This repository was a customized fork of [swagger-api/swagger-ui](https://github.com/swagger-api/swagger-ui) used to provide API documentation rendering for the AWS API Gateway Developer Portal. The functionality provided by this fork has been superseded by the [AWS API Gateway Developer Portal](https://github.com/awslabs/aws-api-gateway-developer-portal) project, and this repository is no longer actively maintained.

## What This Means

- **Historical Reference**: The original codebase remains accessible in the `master` branch of this repository
- **Successor Project**: For current API Gateway developer portal functionality, please refer to the [AWS API Gateway Developer Portal](https://github.com/awslabs/aws-api-gateway-developer-portal)
- **Upstream Project**: For the latest Swagger UI releases, please refer to the upstream [swagger-api/swagger-ui](https://github.com/swagger-api/swagger-ui) repository
- **No Further Updates**: This repository will no longer receive updates or maintenance
